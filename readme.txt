=== WP Thumbhash ===
Contributors: Rasso Hilber
Requires PHP: 8.2
License: GPL-3.0-or-later

Generate and render thumbhash placeholders for your lazy-loaded images 🦦

== Description ==

Uses [ThumbHash](https://evanw.github.io/thumbhash/) to generate and render small
blurry placeholders for your lazy-loaded images during upload.

**→ [Browse the docs on GitHub](https://github.com/hirasso/wp-thumbhash)**
